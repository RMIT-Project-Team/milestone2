Above-average risk demographic profiles

Query 1 calculates the average serious-injury rate across every demographic group. Query 2 uses that result as its input and returns only the profiles sitting above it — surfacing the groups most at risk, not just summarising them.

How this works: the first query groups all crash-involved persons by sex, age and road-user type and finds each group's serious/fatal injury rate. The second query takes that output as a sub-query, keeps only groups above the cross-group average, and ranks them highest to lowest. That nested step is what turns a summary into a discovery.
